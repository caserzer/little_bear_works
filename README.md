# 小熊作业与专项练习

用于保存孩子的作业照片、整理错题，并根据错题生成对应的专项训练，帮助孩子理解知识点、复现解题过程并巩固掌握。

目前先建立资料目录和使用约定；作业识别、错题分析与练习生成尚未实现自动化，可先由家长配合 AI 手动完成。

## 目录结构

沿用现有六年级目录，按学科分别存放资料：

```text
little_bear_works/
├── README.md
└── grade6/                       # 六年级
    ├── Chinese/                 # 语文
    ├── Math/                    # 数学
    └── English/                 # 英语
```

每个学科下均包含以下目录，空目录使用 `.gitkeep` 占位：

```text
Math/
├── homework/                    # 原始作业照片，包括批改痕迹
├── mistakes/                    # 错题整理、错误原因及订正记录
├── practice/                    # 根据错题生成的专项练习及作答照片
└── answers/                     # 练习参考答案与解析，和题目分开保存
```

后续可按相同结构添加其他年级或学科。

## 使用流程

1. **拍照归档**：将完整、清晰的作业照片放入对应学科的 `homework/`，保留题号、题干、孩子的作答及批改痕迹。多页作业按页码排序。
2. **整理错题**：在 `mistakes/` 记录原题来源、孩子的答案、正确答案、考查知识点和错误原因。照片内容不清楚或错因不确定时，先标记“待确认”，核对后再出题。
3. **生成专项练习**：根据已确认的错题，在 `practice/` 保存练习。先安排同知识点、同难度的复现题，再安排少量改变数字、情境或提问方式的变式题。
4. **保存答案解析**：将配套答案放入 `answers/`，写出必要的解题步骤或判断依据，供完成练习后核对。
5. **复习反馈**：将练习作答照片保存到 `practice/`，在原错题记录中补充练习结果。仍有困难的知识点继续练习，后续再通过间隔复习检查是否掌握。

## 文件命名

建议使用 `日期_作业主题或批次_资料类型`，同一批资料保持相同的日期和主题，便于追溯。日期表示原始作业日期，复习日期可另行补充。

以数学分数除法作业为例（以下为命名示例，尚未创建实际资料）：

```text
grade6/Math/homework/2026-09-18_分数除法_作业_01.jpg
grade6/Math/homework/2026-09-18_分数除法_作业_02.jpg
grade6/Math/mistakes/2026-09-18_分数除法_错题.md
grade6/Math/practice/2026-09-18_分数除法_专项练习_01.md
grade6/Math/answers/2026-09-18_分数除法_专项练习_01_答案.md
grade6/Math/practice/2026-09-18_分数除法_专项练习_01_作答_2026-09-20.jpg
```

照片可使用 JPG、PNG 等格式；错题、练习和答案建议先使用 Markdown，便于修改和打印，也可保存为 PDF。

## 错题记录建议

每道错题分配一个批次内唯一编号，如 `Q01`，并记录：

- **来源**：作业照片的相对路径、页码及原题号。
- **题目与作答**：完整题干、孩子原来的答案和正确答案。
- **知识点与错因**：区分概念不清、计算错误、审题遗漏、表达不完整等情况；无法确定的原因保留待确认。
- **订正过程**：记录正确思路，以及孩子能否独立解释。
- **对应练习**：练习文件路径和题号，每道练习注明关联的错题编号。
- **复习结果**：复习日期、完成情况和仍需加强的部分。

## 专项练习原则

- 以孩子当前年级和已学知识为范围，针对具体错因出题。
- 每次先安排少量题目，例如每个知识点 3～5 道，根据完成情况调整。
- 复现题用于检查能否独立完成同类题，变式题用于检查是否理解方法。
- 语文、英语结合错题训练字词、语法、阅读理解或表达；数学结合错题训练概念、计算或应用。
- 生成后核对题目条件、答案和解析，确保题意完整、难度合适。
- 拍照及分享资料时，尽量遮挡姓名、学校等个人信息。
