# 好奇心俱乐部：40集美式英语磨耳朵

围绕六年级英语学习材料制作的原创听力系列。Maya、Leo和机器人Pip在校园、博物馆和科学活动中寻找答案，故事带一点幽默，每集围绕一个小发现展开。

已完成40集，总长约2小时24分钟；实测单集3分21秒至3分52秒，全部低于20分钟。音频含停顿的平均语速约115—143词/分钟。

每集包括：一个听前小问题 → 完整故事 → 简短知识补充 → 换一种说法回顾故事 → 三句常用表达各读两次 → 问题答案与想象题。音频全英文，不含中文翻译或背景音乐。旁白在不同集之间交替使用美式女声和男声，每集内保持一个旁白声音，并非多人广播剧。

## 怎样用来磨耳朵

1. 初次每天选1—2集，先听故事，不必记笔记。喜欢的集数可以连续几天重复听。
2. 如果连人物在做什么都难以听懂，先看一行中文导读和三个词，再听；也可以把播放器调到0.85倍。
3. 第二遍仍有兴趣，再看英文原文或跟读三句话。音频里的问题是可选的小互动，不要求暂停作答。
4. 已经很熟的故事可用1.1倍播放，或换到后面的主题。以能跟上大意、愿意继续听为准，不把听过等同于掌握。

前16集语速参数较慢，后24集略接近自然语速；实际每分钟词数和时长见各集生成记录。内容以常用短句为主，科普新词通过上下文和中文词语提示辅助理解。部分知识说明比日常对话稍难，可以先听故事部分，再反复听整集。

设计参考了已有英语作业中的代词、动词形式、问句、日常搭配和上下文理解方向。**现有材料没有足够听力证据，本系列不是对孩子听力等级的正式测评，也不能用播放次数判断掌握程度。**

## 制作与核验

使用AI合成语音，并非真人录音。声音为 en-US-JennyNeural 和 en-US-GuyNeural。前16集设置 -12%，后24集设置 -8%；这些参数相对于语音自身默认速度，不是固定的每分钟词数。

全部MP3以实际文件时长验证不超过20分钟，并检查是否可完整解码、字幕是否覆盖原文、是否有异常长静音。抽取两种声音各35秒做本地自动语音转写，用于检查开头内容的可辨识性。这些是技术检查，**未进行40集逐集人工试听**；不能据自动检查声称所有重音、停顿或专有词读音都经过人工确认。

需要重新生成时，在项目根目录使用独立Python环境：

~~~bash
python -m venv /tmp/little-bear-audio-venv
/tmp/little-bear-audio-venv/bin/pip install edge-tts==7.2.8
/tmp/little-bear-audio-venv/bin/python scripts/build_english_listening.py
~~~

还需系统提供 ffmpeg 和 ffprobe。生成需要联网；已下载的MP3和播放页使用时不需要联网。只发送原创英文音频稿，不发送孩子作业照片、姓名或个人资料。脚本支持按 --ids 1-8 分批和按记录续跑；--prepare-only 只生成文本，--catalog-only 重建目录与播放页。
