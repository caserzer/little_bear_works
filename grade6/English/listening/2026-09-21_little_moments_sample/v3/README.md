# 生活英语样音 V3：四人分角色配音

根据“对话不要同一个人读，要不同的人读”的反馈制作。同一篇面包店故事、同样的日常内容，改为四种不同的美式合成声音；Lucy同时承担第一人称旁白。

- [试听／下载新版MP3](sample_v3_cast.mp3)
- [打开试听页](试听.html)
- [分角色台词](角色台词.md)
- [英文字幕](sample_v3_cast.srt)

实测时长 **2分23秒**，平均约133词/分钟（含人物切换和停顿）。

## 角色

| 角色 | 声音 | 表达方向 |
|---|---|---|
| Lucy／第一人称旁白 | en-US-MichelleNeural | 沿用V2清亮年轻女声方向 |
| 爸爸 | en-US-GuyNeural | 稳重男声 |
| 面包店店员 | en-US-JennyNeural | 亲切女声 |
| 弟弟 Ben | en-US-EricNeural | 独立男声，轻微提高音高以拉开区别 |

全部角色的语速参数为 +20%；弟弟音高为 +6Hz，其余为原始音高。语音服务没有为这些声音标注精确年龄，“青少年感”仍是试听目标，不宣称是特定年龄的真人录音。样音使用AI合成，无配乐。

按照角色切换将完整故事分成32个语音片段，逐段生成后按原顺序合并。角色切换处额外留0.12秒间隔，合成后的整段音频统一调整响度。字幕按每个片段的实际解码长度累计定位。

generation_receipt.json记录四个声音、各段起止时间、最终时长、音频校验值及解码／字幕一致性检查。技术检查不等于人工试听或对音色的主观评价。

仍先交付这一个故事的样音，新的40集待声音与节奏确认后继续。

## 复现

~~~bash
/tmp/little-bear-audio-venv/bin/python grade6/English/listening/2026-09-21_little_moments_sample/v3/generate_sample.py
~~~

依赖 edge-tts 7.2.8、ffmpeg、ffprobe和生成时的网络连接。临时片段缓存位于 /tmp/little-bear-life-v3-clips；下载的成品MP3可直接离线播放。
