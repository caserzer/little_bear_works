## 建议顺序

1. 优先复习代词、词性与复数、let后原形、过去时、does后的动词原形；再处理语篇选词和阅读回答完整性。
2. 每次一课或半课，先做学生版专项练习，再由家长对答案。L1—L5后做A卷，L6—L8后做B卷和O口语任务。
3. 把错题的首次订正、3天复习和7天复测结果补回记录；R卷在订正约7天后独立完成。
4. 补做原卷时先看待确认表；IMG_5428的Betty篇及IMG_5430的Danny日记缺页，暂不评分。
