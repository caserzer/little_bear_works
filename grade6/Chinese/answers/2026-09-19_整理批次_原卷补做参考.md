# 原卷补做参考（家长版）

本册对应照片中的空白、待完善题及常识复核，供孩子独立补做后核对。阅读、赏析、人物评价接受有文本依据的不同表述；以下不是原学校的标准答案或评分细则。题目与页序见[作业索引](../homework/2026-09-19_整理批次_作业索引.md)，待办编号见[待确认与补做](../mistakes/2026-09-19_整理批次_待确认与补做.md)。

## 一、IMG_5447《管鲍之交》（U01）

1. 断句可为“少时／常与鲍叔牙游”。如分作“少时／常与鲍叔牙／游”，能说明主干也可；不要在“鲍叔牙”姓名内部停顿。
2. 释词参考如下，具体词义依原句判断。

| 字词 | 本文意思 |
|---|---|
| 少 | 年轻、年少 |
| 游 | 交往 |
| 善 | 友善地、好好地 |
| 遇 | 对待 |
| 已而 | 不久、后来 |
| 事 | 侍奉、辅佐 |
| 及 | 等到 |
| 遂 | 于是、就 |
| 进 | 推荐 |
| 既 | 已经；“既用”指被任用以后 |
| 以 | 因此、凭借管仲的辅佐 |
| 合（题栏作“会”） | 会集、会盟 |
| 谋 | 谋划、计谋 |

3. 翻译：“齐桓公因此称霸，多次会盟诸侯，匡正天下，这都是管仲谋划的结果。”要点是因果关系、会盟诸侯、功劳归于管仲。“九”在这里可理解为多次，不必机械限定为恰好九次。
4. 选C：鲍叔牙了解管仲的才能，认为他能够胜任。原作答已正确。
5. 管仲有才干、善于谋划，依据是辅佐齐桓公称霸等政绩；鲍叔牙知人善任、宽厚待友，依据是了解管仲之贤，始终善待他，并推荐他。人物评价必须各有依据，不只罗列好词。

## 二、IMG_5447《刘柳情谊》（U02）

1. “时”：当时；“谓”：对……说。
2. “胡忍见其若是”：怎么忍心看到他这样呢？选A。“胡”表示怎么，“其”指刘禹锡，“若是”指像这样。
3. 刘禹锡的母亲年事已高，播州偏远、路途遥远，难以随行；若母子分处两地，可能再难相见。柳宗元不忍朋友面临这一处境，所以请求把柳州让给刘禹锡，自己前往播州。原因与行动要说完整。
4. 表现重情重义、体恤朋友、愿意为朋友承担困难的美德。证据是“请以柳州授禹锡，自往播州”。不要把最后改任连州误写成柳宗元请求交换已经原样获准。

## 三、IMG_5445《河阳猪》复核

1. “市”在文中作动词，意思是买；文中意思相近的字为“贾”。
2. “以为非他产所能及也”：大家认为其他地方出产的猪肉都比不上这猪肉。结合全文，可补充“他们以为吃到的是河阳猪肉”。原答已经表达主要比较关系，完善语意即可。
3. 第3题选C，讽刺只信名声、缺乏实际判断。故事中先称赞，后来得知真相又惭愧，构成对照。

## 四、IMG_5448、5453古诗词常识与注释（U11—U15）

| 内容 | 规范表述 |
|---|---|
| 孟浩然 | 唐代诗人，山水田园诗派代表诗人之一 |
| 苏轼 | 字子瞻，号东坡居士，宋代文学家 |
| 辛弃疾 | 字幼安，号稼轩，宋代词人 |
| 西江月 | 词牌名；“夜行黄沙道中”是词题 |
| 泊 | 停船靠岸；“停泊”意思也成立 |
| 渚 | 水中的小块陆地 |
| 日暮 | 傍晚，太阳将落的时候 |
| 客 | 旅居在外的人；此处指诗人自己 |
| 翻墨 | 像打翻的墨汁，写出乌云浓黑、翻滚的样子 |
| 卷地 | 从地面卷起、贴着地面席卷而来；不是只解释成“大风” |
| 别枝 | 横斜的树枝 |
| 茅店 | 茅草盖的小客舍 |
| 社林 | 土地庙附近的树林 |
| 见 | 读xiàn，同“现”，出现 |

《宿建德江》以“愁”贯穿，表现客居的孤寂、思乡等情绪；《西江月·夜行黄沙道中》写乡间夏夜景物，呈现闲适、喜悦和对田园生活的喜爱。判断情感须联系诗句，不规定只能用一个形容词。孟诗的客愁解读可参见[华东师范大学：孟浩然田园诗赏析](https://www.ecnu.edu.cn/info/1095/61115.htm)。

默写复核：

- “卷地风来忽吹散，望湖楼下水如天。”
- “野旷天低树，江清月近人。”
- “稻花香里说丰年，听取蛙声一片。”

原卷已写对的默写不用重新列为错题；只按实际遗漏或错字订正。

## 五、IMG_5450《丁香结》补做（U03、U04、U16）

第5题按六个自然段的课文分为：第1—3段写丁香花，第4—6段写丁香结。前者从不同场景描写花的色彩、形态、香气等；后者从花苞的形状、诗句的联想，写到人生中的烦恼和结，以及面对它们的态度。若手边版本分段不同，以内容边界为准。花与结两部分的阅读关系可参见[人民教育出版社阅读教学资料](https://www.pep.com.cn/bks/xxyw/jzjd/202505/W020250531383043079666.pdf)。

字音核对：嚣xiāo、缀zhuì、窥kuī、拙zhuō、参差cēn cī、莹yíng、簇cù、薄bó（“单薄”中）。

第6题可提出具体疑问，例如：“为什么作者说年年都有丁香结，生活中的问题也是解不完的？作者希望我们用什么态度面对它？”这是提问示例，孩子应写自己的真实疑问，再尝试从结尾寻找解释。

## 六、IMG_5453第16—17题（U05、U06）

**第16题修辞赏析：**“翻墨”把乌云比作打翻的墨汁，写出乌云浓黑、翻滚的特点；“跳珠”把雨点比作跳动的珍珠，写出雨点密急、落船弹跳的动态。两处比喻把骤雨来临时的景象写得具体鲜明。答题时对应好事物、比喻对象、特点，避免只有“生动形象”。

**第17题借景抒情，不少于60字。**先确定心情，再选两三种景物，用声音、颜色或动作表现。下面是本次原创范例，不用于直接替代孩子作答：

> 傍晚，我独自走在回家的小路上。风把一片枯叶推到脚边，又轻轻卷走。远处窗户一盏盏亮起来，饭菜的香气从门缝飘出。我放慢脚步，想起奶奶以前总在巷口等我，那声熟悉的呼唤仿佛还留在风里。

核对重点：达到字数；有具体景物；景物与心情一致；有自然的情感联系。快乐、思念、惆怅等均可，不要求都写悲伤。

## 七、IMG_5453—5454《枭将东徙》（U07）

1. “子将安之”：你打算到哪里去？选C。子：你；将：将要；安：哪里；之：去、往。
2. 用原文回答迁居原因：“乡人皆恶我鸣。”即乡里的人都讨厌我的叫声。“恶”在此读wù，意思是厌恶。
3. 选D。寓言语境中，若叫声这个原因不改变，仅换地方仍会遇到相同问题，强调发现自身问题后要作出改变。结合鸠的劝告回答，不把寓言扩展为对所有现实处境的绝对结论。

## 八、IMG_5454《母亲的蒲公英》（U08）

**第4题，第②段的蒲公英有哪些特点？**不挑选生长环境，能在异乡土地扎根；不畏寒霜、木石等条件，顽强生长；尚未到春天已开始繁殖，表现坚韧、旺盛的生命力。概括特点后能联系一两处描写即可，不要求照抄整段。

**第5题，两次“心疼”如何理解？**第一次看到蒲公英生长处正是母亲的坟墓，触发丧母的悲痛与思念。后来由蒲公英的坚韧想到母亲在艰苦生活中养育子女、始终牵挂孩子，既心疼母亲多年辛劳，也感激、怀念她；母亲已逝，又让人感到失落与伤痛。两处要联系各自上下文，不能只重复“难过”。

**第6题，末两段的作用是什么？**

- 内容上，再写抚摸蒲公英的动作和感受，把蒲公英的坚韧与母亲的刚强、温暖联系起来，表现对母亲的思念和赞美，也让人感到母爱仍留在心中。
- 结构上，从回忆母亲回到坟前的蒲公英，照应开头的发现和前文的“心疼”，以触摸叶片仿佛感到母亲爱抚的感受收束全文。
- 表达上，借具体植物寄托情感，使抽象的思念变得可感。只写“照应开头、深化主题”而没有对应内容，答案仍不完整。

## 九、IMG_5452人物学案（U09、U10）

“小试牛刀”建议先写150—200字片段，选一个特点、一件小事、两处细节。本批字数是训练建议，原题未限定。可分析范文如何表现人物：例如陈芋汐“教毛巾跳水”的具体动作体现主动琢磨、改进方法；谢企华的衣着、说话方式和处理工作的小事共同形成人物形象。结论要来自原文，不补造人物经历。

小组选题与分工使用[人物观察与采访记录](../practice/2026-09-19_整理批次_人物观察与采访记录.md)。个人在家练习可只填观察部分；课堂小组任务由实际成员填写姓名和职责。采访问题先拟定，得到真实回答后再记实录；没有回答的栏保持空白。
