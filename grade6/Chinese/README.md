## 使用顺序

1. 按作业索引核对原图，先看错题本中的原答和订正。
2. 按薄弱点选择对应教案，每次一课；完成该课4道专项练习。
3. 回到原卷完成空白题，再核对补做参考。人物任务使用观察记录表。
4. 分次完成A、B考核，记录失分题号并回到相应课次；约3天后口头抽查，7天后完成R卷。
5. 将独立订正、再次出错和复测情况填回错题本。能解释并迁移运用后再标记掌握。
