## 建议顺序

1. 先读错题记录，优先关注三个数的公倍数、分数基本性质、比较基准、剩余问题、面积单位换算。
2. 按教案做对应专项练习，每次一课或半课；答案由家长单独保管。
3. L1—L3结束做A卷，L4—L8结束做B卷，再按失分题回到对应课次。
4. 订正后3天做口头解释与变式，7天做R卷，把表现补回错题记录。
